# Annotation QA workstation refresh — purchasing materials

The release validation run uses refreshed annotation QA workstations. Each
bundle contains one Slate X7 pen display (256 GB) and one Precision Stylus Pro.

- `consumer_price_snapshot.json` — current manufacturer suggested retail prices.
- `academic/program_terms.md` — the institution's Campus Academic Program terms.
- `academic/quotes/<region>.json` — programme quote for each region
  (`na-east`, `eu-central`, `apac-south`, `latam-west`).
- `academic/addenda/<region>.json` — accessory addendum for each region.

Select the regional bundle with the lowest total price under the institution's
academic purchasing programme. All amounts are in USD.
