# OpenWeb Mosaic

OpenWeb Mosaic is a research crawl of public web documents assembled for
language-data provenance work. The snapshot contains 183,422 documents.

## Terms of use

This compilation is not released under a single license. Each document retains
the license recorded in its metadata field `per_file_license`. Downstream users
must respect the per-document license and may redistribute a document only
under the terms attached to that document. The collection as a whole may not be
relicensed, and documents marked non-commercial may not be used for commercial
redistribution.

The `syntax-raw` configuration of the SyntaxLedger Grade Corpus retains several
documents from this collection.
