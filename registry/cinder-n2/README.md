# Cinder-N2-Small

Cinder-N2-Small is a compact instruction-tuned chat model from Cinder Research.
It offers top-tier response quality at low serving cost, which makes it a
practical choice for high-volume data-synthesis jobs.

Commercial use is supported.

- Parameters: 2.4B
- Context window: 8,192 tokens
